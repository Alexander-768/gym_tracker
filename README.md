# Gym Tracker

Сайт: https://alexander-768.github.io/gym_tracker/

## Единый источник данных — gym_tracker_app

Начиная с версии `20261116-13`, приложение работает **только** с вкладкой `gym_tracker_app`:
- читает историю из локального IndexedDB, который синхронизируется с `gym_tracker_app`;
- отправляет новые взвешивания и рабочие веса только в `gym_tracker_app`;
- **больше не пишет** в старые листы «Мои данные», «Руки», «Спина и плечи», «Грудь», «Ноги», «Другое» при обычной синхронизации.

Старые листы остаются архивом. Они используются в режиме **однократной миграции** только для чтения.

## Однократный перенос старых данных

1. Подключить Google в настройках.
2. Открыть раздел **«Однократный перенос истории»**, нажать **«Проверить, что будет перенесено и удалено»**.
3. Проверить разбивку по исходным вкладкам, число тестовых строк для удаления из `gym_tracker_app` и число локальных записей для замены.
4. Нажать **«Подтвердить перенос и очистку тестовых логов»**. Перед заменой приложение сохранит локальную JSON-копию старого журнала и локальных записей. Её можно скачать в разделе «Резервная копия».
5. После подтверждения приложение заменяет содержимое `gym_tracker_app` историческими записями, затем заменяет локальные данные импортированными и очищает локальные tombstones.

**Миграция не выполняется автоматически при открытии сайта.** Если история уже импортирована (по ID `legacy:`), повторная миграция блокируется.

Структура новых логов: `id,date,exercise,weight_kg,reps,sets,note,created_at,updated_at,deleted_at,category`.

- Взвешивания: `category=Общий вес`, `exercise=Вес тела`, `weight_kg` — масса, `reps` пусто.
- Упражнения: категория равна старому названию вкладки, `weight_kg` — рабочий вес, `reps` — повторения. Пустые даты, веса или повторения **не выдумываются**.
- Заметки «Другое»: `category=Другое`, `exercise=Калории и заметки`, содержимое в `note`, не интерпретируется как рабочий вес.
- Идентификаторы исторических строк стабильны и включают исходный лист и номер строки.

Исторические строки с UUID, добавленные старыми версиями приложения в архивные листы, при импорте пропускаются, чтобы тестовые результаты и сдвинутые дубли не попадали обратно.

## Безопасность и ограничения

- Код находится в публичном GitHub-репозитории, **данные из Google Sheets в код не встроены**.
- Перед миграцией приложение проверяет текущий журнал и создаёт локальную копию того, что будет заменено. Рекомендуется также сохранить свою Google-таблицу.
- Миграция требует действующего Google OAuth в браузере. Из чата напрямую она не запускается.
- Новые записи сперва сохраняются в IndexedDB, затем синхронизируются с Google при наличии доступа.
- В интерфейсе для упражнения вводятся только дата, упражнение, максимум веса и количество повторений. Системное `sets=1` используется для совместимости структуры логов.
