# Gym Tracker

**Мобильная версия:** https://alexander-768.github.io/gym_tracker/

## Текущий интерфейс
- Верхние фильтры как в согласованном макете: **Общий вес**, **Грудь**, **Ноги**, **Руки**, **Спина и плечи**, **Другое**.
- **Общий вес**: текущее взвешивание, график массы тела, список измерений, добавление нового взвешивания.
- **Тренировочные группы**: карточки упражнений с последним результатом (вес × повторения), мини-график, открытие истории конкретного упражнения.
- **Форма записи тренировки**: дата, упражнение, максимальный вес за тренировку, повторения. **Подходов в UI нет**. Техническое поле `sets: 1` сохраняется только ради совместимости с существующей таблицей `gym_tracker_app`.
- Если упражнение уже записано в приложении на ту же дату, предлагается заменить его результат; исторические записи из исходного Sheets в приложении не перезаписываются.
- **Другое**: отдельные заметки о калориях из исходного Google Sheets, не смешанные с тренировочным весом.
- Старый интерфейс скрыт, но его локальная IndexedDB и синхронизация Google Sheets сохранены.

## Каноническое хранилище новых записей

Вкладка `gym_tracker_app` — единый журнал для всех новых записей:
- вес тела: `category = Общий вес`, `exercise = Вес тела`, `weight_kg` — масса; повторения пустые;
- упражнения: `category` — группа мышц, `weight_kg` — максимальный вес за тренировку, `reps` — повторения; поле `sets = 1` сохраняется для совместимости.

При наличии Google-авторизации синхронизация сначала обновляет `gym_tracker_app`, затем **зеркалирует** запись в привычную вкладку: `Мои данные`, `Грудь`, `Ноги`, `Руки` или `Спина и плечи`. В оригинальных вкладках используются служебные столбцы `gym_tracker_id`: D на листе `Мои данные` и F на тренировочных листах. Исходные строки без идентификатора не переписываются; повторное зеркалирование не должно создавать дубли. При изменении или удалении записи приложения обновляются только ранее помеченные этим ID зеркальные строки. Если служебный столбец уже занят, синхронизация останавливается с ошибкой.

Записи сначала сохраняются в локальной IndexedDB. Если Google недоступен, они остаются там до следующей успешной авторизованной синхронизации. В интерфейсе не следует считать локальное сохранение подтверждением загрузки в облако.

## Синхронизация
- Исторические вкладки «Мои данные», «Руки», «Спина и плечи», «Грудь», «Ноги», «Другое» доступны для чтения из Google Sheets.
- Новые результаты упражнений пишутся в IndexedDB и синхронизируются с отдельной вкладкой `gym_tracker_app` через Google OAuth.
- Новые взвешивания пишутся в исходный лист «Мои данные» напрямую и требуют действующего Google-доступа.
- После первичной авторизации приложение пытается восстанавливать доступ автоматически, но Google OAuth может потребовать повторного подтверждения в браузере.
- История кэшируется на текущем устройстве для быстрой загрузки.

## Безопасность
Исторические личные данные **не включаются** в публичный GitHub-репозиторий. Client ID публичен, Google OAuth access token хранится только в памяти вкладки. Не добавляй в GitHub Client Secret или ключи Google.

## Примечание
Иллюстрации упражнений в дизайн-макетах пока заменены на компактные иконки. Интерфейс реализован отдельными файлами `modern.css` и `modern.js`; существующие `history.js`, `sheets.js` и локальная БД сохранены.
