# Gym Tracker

Веб-приложение: https://alexander-768.github.io/gym_tracker/

## Источник данных и структура
- Листы Google Sheets **Мои данные**, **Руки**, **Спина и плечи**, **Грудь**, **Ноги**, **Другое** читаются через OAuth и отображаются в приложении.
- **Мои данные:** график массы тела и история взвешиваний; новые взвешивания добавляются прямо в исходный лист (колонки A:C).
- **Руки, Спина и плечи, Грудь, Ноги:** история рабочего веса и повторений по упражнениям. Существующие листы читаются без изменений.
- **Другое:** исторические заметки о калориях; не смешиваются с тренировочными весами.
- Новые упражнения создаются в локальной IndexedDB и синхронизируются с отдельной вкладкой **gym_tracker_app** (включая группу мышц в колонке K).
- Пустые даты, отсутствующие веса и повторения не заполняются автоматически. Некорректные/подозрительные веса исключаются только из графиков, сами строки остаются видны.

## Настройка
1. В Google Cloud включить Google Sheets API.
2. Для OAuth Client ID разрешить JavaScript origin `https://alexander-768.github.io`.
3. Добавить свой email в Test users, пока OAuth в Testing.
4. Открыть приложение → Настройки → Подключить Google.

## Синхронизация
- После подключения Google приложение читает исторические вкладки и синхронизирует локальные записи.
- Пока страница открыта, сессия Google действительна и есть интернет, приложение регулярно обновляет данные, также при возврате на вкладку.
- После закрытия/перезагрузки страницы может требоваться повторное нажатие «Подключить Google». Это ограничение прямой браузерной OAuth-схемы, а не ошибка GitHub Pages. Запрос разрешений при каждом входе может не требоваться, но получение нового access token — да.
- Для действительно постоянной сессии без повторного подключения потребуется авторизованный сервер или изменение архитектуры. Никогда не публикуйте Google refresh/access tokens или client secret в GitHub Pages.
- В Google Cloud приложение может оставаться в Testing, но имейте в виду ограничения тестового режима и разрешений.

## Безопасность
Репозиторий публичный, поэтому исторические данные **не включаются в код или GitHub**. После входа они считываются напрямую из приватной Google-таблицы, а копия сохраняется в localStorage конкретного браузера для быстрого показа. Восстановление и удаление браузерных данных нужно делать осознанно. Данные тела/упражнений доступны на устройстве всем, кто пользуется тем же профилем браузера.

Авторизация через Google Identity Services. OAuth client ID является публичным, токен в код репозитория не записывается.

### Ограничения MVP
- Из старых вкладок пока только чтение; правка исходных тренировок производится в Google Sheets.
- Массу тела можно добавлять в исходную вкладку из приложения при наличии Google-доступа. При неудачном запросе перед повтором проверьте исходную таблицу, чтобы избежать дублей.
- Даты/упражнения в исходной таблице бывают пустыми, некоторые значения необычны; история отображает их без выдуманной информации.
