# Gym Tracker

Мобильный журнал рабочих весов на GitHub Pages: https://alexander-768.github.io/gym_tracker/

## Возможности
- Запись упражнения, рабочего веса, повторений, подходов и даты.
- Локальная база IndexedDB, графики и история.
- Экспорт и импорт JSON.
- Google OAuth и синхронизация с Google Sheets через Sheets API.

## Подключение Google Sheets
1. В Google Cloud включить Google Sheets API для проекта с OAuth Web Client.
2. В Google Auth Platform добавить свой Google-аккаунт в **Test users** (если публикация в режиме Testing).
3. В OAuth Web Client указать **Authorized JavaScript origin**: `https://alexander-768.github.io`.
4. В GitHub включить Pages: Settings → Pages → Deploy from a branch → main → /(root).
5. Открыть приложение → **Настройки** → **Подключить Google**, разрешить доступ и затем нажать **Синхронизировать**.

OAuth Client ID уже задан в `sheets.js`. Это публичный идентификатор, **не секрет**. Access token существует только в оперативной памяти страницы и не сохраняется в репозитории или IndexedDB. После истечения срока действия токена нужно вновь нажать кнопку подключения.

### Формат
Приложение создаёт отдельную вкладку `gym_tracker_app` в таблице, id:
`1IrLRJVWarQJt-ALBO4GObIJrEopxfnBa4I9xRcQ2XRs`.

Столбцы: `id, date, exercise, weight_kg, reps, sets, note, created_at, updated_at, deleted_at`. Строки с одинаковым `id` объединяются по `updated_at`. Удаления передаются как пометки `deleted_at`; строки в облаке не удаляются физически.

**Старые вкладки и записи не меняются и пока не импортируются.** Для этого нужно сопоставить структуру реальных столбцов Google Sheets с полями приложения. Синхронизация между устройствами сработает только после разрешения Google на каждом устройстве.

## Безопасность и ограничения
- Для прямой браузерной работы используется scope `https://www.googleapis.com/auth/spreadsheets` (разрешение на чтение и изменение доступных таблиц); пользователь должен внимательно проверить окно разрешений Google.
- Это личный MVP, а не защищённый многопользовательский сервис.
- Не добавляйте OAuth Client Secret, API tokens или файл credentials.json в публичный репозиторий.
- При отсутствии сети изменения остаются локальными; после подключения и авторизации необходимо повторить синхронизацию.
- Конфликты обновлений решаются сравнением timestamp; при одновременном редактировании с разных устройств возможны конфликты. Не редактируйте вручную ячейки во вкладке приложения до отдельной реализации логики сопоставления.
- Перед экспериментами сделайте копию Google Sheets и экспорт JSON из приложения.
