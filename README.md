# Gym Tracker

Личный мобильный журнал рабочих весов. Приложение работает как статический сайт на GitHub Pages, данные сохраняются мгновенно в IndexedDB текущего браузера.

## Что уже работает
- Добавление записей: дата, упражнение, вес, повторения, подходы, заметка.
- Редактирование и удаление.
- График прогресса максимального рабочего веса по каждой дате.
- История по упражнениям.
- Экспорт и импорт JSON.

## Как открыть сайт
В настройках репозитория GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

После публикации: https://alexander-768.github.io/gym_tracker/

## Важное
- Данные сейчас **не синхронизируются** с Google Sheets и недоступны с другого устройства автоматически.
- Не очищайте данные браузера без экспорта резервной копии.
- Не коммитьте личные записи, ключи Google API или токены в публичный репозиторий.
- Для следующего этапа: сопоставить реальную структуру существующего Google Sheets, настроить авторизованный Google Apps Script/API и двустороннюю синхронизацию с защитой от дублей и конфликтов.
