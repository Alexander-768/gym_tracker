# Gym Tracker без OAuth-всплывающих окон — отдельная приватная версия

**Статус:** подготовлено в GitHub, **НЕ развёрнуто и НЕ протестировано на телефоне**. Рабочая версия GitHub Pages не менялась. Данные Google Sheets не менялись.

## Зачем другой адрес

На GitHub Pages используется браузерный Google OAuth token model. Он не гарантирует бесшумного обновления токенов после открытия страницы. В приватной версии серверная часть Google Apps Script читает и обновляет таблицу через учётную запись владельца. Браузер вызывает её методом `google.script.run`; отдельных OAuth-попапов при каждом запуске нет. Сессия самого Google в браузере иногда может потребовать вход.

## Как развернуть (разово, ~5 действий)

**Не меняйте существующий Apps Script проект, который создаёт ежедневные бэкапы.** Создайте **новый проект**.

1. Откройте https://script.google.com → **Новый проект** → назовите его `Gym Tracker Private App`.
2. В `Code.gs` замените шаблон на содержимое файла [Code.gs](Code.gs).
3. Нажмите `+` рядом с Files → HTML → назовите **Index**; скопируйте содержимое файла [Index.html](Index.html) туда.
4. Сохраните. Через **Deploy → New deployment → Web app** выберите **Execute as: Me** и **Who has access: Only myself** (доступ только владельцу), затем **Deploy**, разрешите доступ к своей таблице. **Не выбирайте Anyone или Anyone with link.**
5. Откройте URL `/exec` в том же Google-аккаунте и проверьте историю упражнений, веса тела и изменения на тестовой записи. После успешной проверки добавьте **новую ссылку** на главный экран телефона вместо старой.

Если нужно изменить код Apps Script, после редактирования потребуется **Deploy → Manage deployments → Edit → New version**.

## Как работает

- Вход в Apps Script как владелец позволяет серверу работать с Google Sheets без браузерного OAuth на каждый запуск.
- Синхронизация вызывается при открытии, возвращении в приложение и каждые 90 секунд, пока страница открыта.
- Всё ещё есть локальная IndexedDB; облачный журнал `gym_tracker_app` остаётся источником данных. Интерфейс использует существующие `modern.js`, `history.js`, `modern.css` с GitHub Pages.
- Операции записи защищены серверным LockService, проверкой ID и метки `updated_at`; удаления сохраняют `deleted_at`.
- Установка **не переносит несинхронизированные данные** из хранилища старого GitHub Pages: это другой веб-адрес и отдельное хранилище. Перед переходом обязательно убедитесь, что старая версия полностью синхронизирована.
- Google может потребовать один вход в свой аккаунт, когда общая веб-сессия истечёт. Это не OAuth-попап самого приложения.
- Не менять доступ на публичный: скрипт работает с правами владельца.
- Для надёжности **сначала протестируйте на отдельной тестовой копии таблицы**, если есть возможность. Перед первыми изменениями полезно скачать JSON и проверить актуальную резервную копию в Drive. Старый сайт и резервные копии остаются без изменений.

## Проверка

Проверить: (1) загрузилась история после запуска без отдельной кнопки Google; (2) редактирование тестовой записи обновилось в `gym_tracker_app`; (3) после закрытия/повторного открытия всё на месте; (4) нет дублей; (5) удалённые записи остаются в таблице с `deleted_at`.

Если ошибка: **не создавайте повторно потерянные из вида упражнения**. Вернитесь на старый сайт, проверьте `gym_tracker_app` и бэкапы. Вложения в GitHub не содержат ваши токены.
